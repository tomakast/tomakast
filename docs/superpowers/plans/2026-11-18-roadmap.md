# tomakast: дорожная карта планов для первой спецификации

Спецификация: `docs/superpowers/specs/2026-11-18-tomakast-core-design.md`.

Спецификация охватывает несколько подсистем, поэтому она разбита на последовательные планы. Каждый план даёт работающую и проверяемую программу.

| # | План | Результат | Зависит от |
|---|------|-----------|------------|
| 1 | `2026-11-18-plan-1-foundation-linux.md`: ядро, окно лаунчера и поиск приложений на Linux | Демон на KDE/Wayland: по хоткею открывается лаунчер, ищет и запускает приложения, ранжирует по использованию. Плюс переносимый бинарник-эксперимент окна для macOS и Windows | — |
| 2 | Плагинный хост и WASM: WIT 0.1, манифест, разрешения, представления, `calc` | Сторонний WASM-плагин грузится из папки без пересборки. Представления list/grid/detail/form/action-panel/scratchpad/toast. Калькулятор-scratchpad. Модель угроз из спецификации. Дополнительные действия `apps` («показать в файловом менеджере», «скопировать путь») через action-panel | 1 |
| 3 | macOS: окно (non-activating panel), хоткеи, `apps` для `.app`, автозапуск | Тот же функционал, что в плане 1, на macOS, проверен на маке пользователя | 1 (лучше после 2) |
| 4 | Windows: окно (tool-window), `RegisterHotKey`, `apps` для Start Menu, автозапуск | То же на Windows, проверено на машине пользователя | 1 (лучше после 3) |

Пункт 1 спецификации требует до основной UI-работы провести эксперимент с окном на Linux и macOS. Поэтому в плане 1 есть задача, которая собирает переносимый бинарник-эксперимент. Пользователь запускает его на маке и на Windows до старта плана 3. Если результаты на маке окажутся плохими, порядок планов пересматривается.

После плана 2 WIT 0.1 и формат манифеста зафиксированы. Начиная с этого момента следующие спецификации (диктовка, клипборд, окна, конвертер, переводчик, caffeinate, заметки, поиск файлов, синхронизация, менеджер плагинов) можно вести параллельно.
